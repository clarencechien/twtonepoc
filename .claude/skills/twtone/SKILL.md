# twtone

兩層確定性工具，先跑再談，不要自己用「感覺」判 AI 味。

## 怎麼跑

```bash
./twtone <檔案.md>            # 預設快速模式：只列超過台灣基準的項目
./twtone <檔案.md> --verbose  # 連注意級一起展開
./twtone <檔案.md> --gate     # 發佈前關卡：有嚴重項 exit 1
./twtone <檔案.md> --full     # 完整報告（所有命中，含 zhtw-mcp 翻譯腔）
```

第一次執行會自動下載 zhtw-mcp binary（`setup.sh`）。
目標若是 HTML 報告，先把正文抽成 .md 再跑（表格、程式碼區塊會被忽略）。

## 讀輸出的規則

- **「要改」區**：這些句子超過 AI 之前台灣同類文體任何一篇的密度。對每一句給一個最小改法，保留原句的事實與限定詞；原句若是在澄清誤讀、引文、或刻意的修辭，說明理由後可以保留。不要把六句全改成同一種寫法。
- **「略過」區**：不要主動建議修改。使用者問起才解釋為什麼略過（體裁差異、低於門檻、X 級已被研究否決）。
- **用詞區**：唯一候選的兩岸用詞已自動改進 `<檔名>.tw.md`，原檔沒動。把 diff 給使用者看，由他決定要不要採用。多候選的用詞列出來讓他選。
- **翻譯腔 warning**：不自動改。只有使用者要求時才逐句處理，而且只拆句、不換詞。

## 絕對不做

- 不重寫全文、不「潤飾」整段。研究（arXiv 2511.04195、2605.19516）顯示 LLM 整篇改寫去 AI 味效果差且損失語義。
- 不為了「節奏」改句長、不製造長短參差。句長 CV 是只報告項。
- 不動 X 級：精確數字、首先／其次、「這意味著」、一二三編號。配對研究已否決這些是 AI 味。
- 不動引文（「」『』內）和標題。

## 門檻從哪來

`out/baseline-pre2022.json`：2015–2022 台灣科技評論／科普／解釋型長文 11 篇（iThome、INSIDE、泛科學、報導者），來源在 `corpus/SOURCES.md`。
嚴重 = 超過基準最大值；注意 = 超過 p75。要重算：`./twtone --baseline <檔案.md>`。

## 已知限制

- 基準只有 11 篇，稀有訊號（對舉、結論冒號）用合併口徑，不用中位數。
- zhtw-mcp 的「用戶→使用者」「數據→資料」是教育部規範立場；2015–2022 的台灣記者也大量用「用戶」「數據」。這兩條要不要改是立場，不是對錯，由使用者在 `overrides.json` 決定。
- 「扮演」「持久的」等 zhtw-mcp ai_style 命中在報告體裁多為誤報，quick 模式不顯示。
